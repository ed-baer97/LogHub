# Документация Caspian LogHub

Цифровая биржа внутрирегиональных грузоперевозок Мангистауской области. Отправитель размещает заявку, перевозчик берёт её на компанию и назначает борт, водитель проводит рейс по этапам. Попутные грузы закрывают порожний возврат.

Кейс — только перевозки внутри области (магазины, фермы, стройки, отдалённые посёлки). Не порт и не международный транзит.
