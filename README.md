# Caspian LogHub

Цифровая биржа **внутрирегиональных** грузоперевозок Мангистауской области: заявки отправителей, GPS автопарка, попутные грузы вместо порожнего возврата, админка грузопотоков для акимата.

Кейс — только перевозки внутри области (магазины, фермы, стройки, отдалённые посёлки). Не порт и не международный транзит.

## Как устроен интерфейс

- **Главная (`/`)** — страница о проекте: проблема, решение, роли, экономика. Карты и кабинетов здесь нет.
- **Войти** — кнопка в шапке (или на лендинге) открывает окно авторизации: email + пароль.
- **После входа** открывается кабинет роли. Чужой кабинет по прямой ссылке недоступен. Выход возвращает на главную.

| Роль | Кабинет |
|------|---------|
| Супер-админ | Дашборд системы (просмотр). Создаёт **только админов**, правки не вносит |
| Админ | Админка: обзор, заявки, автопарк, пользователи, пункты. Создаёт отправителей, перевозчиков и водителей. **Админа создать не может** |
| Отправитель | Новая заявка / мои заявки, расчёт цены, трек на карте |
| Перевозчик | Биржа / мои рейсы, попутки, взятие заказа |
| Водитель | Карточка рейса, трансляция GPS с телефона |

Быстрый сценарий для жюри:

1. `sender@caspian.kz` / `demo` — заявка, например Актау → Шетпе.
2. Выйти. `carrier@caspian.kz` / `demo` — взять заказ (лучше с бейджем попутки).
3. Выйти. `dispatcher@caspian.kz` / `demo` — админка: карта, назначение машин, парк, пункты. Во вкладке «Пользователи» — отправитель / перевозчик / водитель (админа создать нельзя).
4. `superadmin@caspian.kz` / `demo` — дашборд системы и создание админов; заявок, парка и пунктов нет.
5. `driver@caspian.kz` / `demo` — «Начать трансляцию» (нужно разрешение геолокации в браузере).

Новых пользователей с паролем `demo` создаёт админ (не админов) или супер-админ (только админов).

## Что умеет MVP

1. **Биржа.** Заявка между реальными пунктами Мангистау, лента для перевозчика, статусы.
2. **Карта и GPS.** MapLibre + OSM. Симулятор ведёт машины по полилиниям OSRM. Live-геолокация водителя перекрывает симулятор.
3. **Попутки.** Коридор маршрута: крюк, сэкономленные км порожняка, литры и тенге.
4. **Цена.** Рекомендация по км, весу и типу груза (исторические рейсы области).
5. **Админка.** Админ назначает / отменяет заявки, ведёт парк и пункты. Супер-админ видит дашборд системы и создаёт админов, правки не вносит.

## Стек

- Backend: FastAPI, SQLAlchemy 2, PostgreSQL (Docker) или SQLite локально, SSE
- Frontend: React 18, Vite, MapLibre GL
- Маршруты: публичный OSRM, кэш в БД

## Локальный запуск

Если Docker Desktop выключен, бэкенд по умолчанию пишет в **SQLite** (`backend/caspian.db`) — это настоящая БД, не localStorage.

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux:   source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Открыть **http://localhost:5173** — Vite проксирует `/api` на бэкенд. Документация API: http://127.0.0.1:8000/docs

Первый старт создаёт таблицы и сид: 25 пунктов Мангистау, машины, заявки, учётки выше. Подтягивание OSRM — около 10–20 секунд.

PostgreSQL вместо SQLite:

```bash
docker compose up -d postgres
# Windows PowerShell:
$env:DATABASE_URL="postgresql+psycopg://caspian:caspian@localhost:5432/caspian"
```

## Продакшен на Linux (Docker + публичная ссылка)

```bash
docker compose up --build -d
```

Фронт: порт **80**, API: **8000**. Скрипт: `scripts/deploy-linux.sh`.

Публичный URL без белого IP:

```bash
cloudflared tunnel --url http://localhost:80
```

Запасной вариант: `ngrok http 80`.

## Экономика (питч)

- Без биржи порожний пробег ~**40%**.
- Обратная загрузка в коридоре маршрута (детур ≤ 90 км).
- Дизель **32 л / 100 км**, **295 ₸/л**.
- Выигрывают перевозчик (топливо), отправитель (срок и цена), акимат (видимость потоков).
